# Руководство для AI-агентов (`tld-wiki-guide`)

## Архитектурные слои (`L0–L5`)
Проект следует строгой однонаправленной иерархии слоёв (проверяется командой `npm run check:layers`):
- `L0` (`src/l0-primitives`): базовые типы, математика координат, константы, текстовая нормализация. Не импортирует `L1–L5`.
- `L1` (`src/l1-codecs`): парсинг и санитизация внешних данных (MediaWiki Fandom API, импорт/экспорт JSON дневника, `localStorage`). Может импортировать только `L0`.
- `L2` (`src/l2-models`): база знаний энциклопедии, регионы, маркеры карты, чистые функции фильтрации и расчёта прогресса (Reference Oracle для тестов). Может импортировать `L0–L1`.
- `L3` (`src/l3-commands`): единый реестр команд (`executeCommand`) и хранилище состояния сессии. Доступен также через `window.__TLD_COMMANDS__`. Может импортировать `L0–L2`.
- `L4` (`src/l4-renderers`): генераторы угольных SVG-карт в стилистике *The Long Dark* и иконки маркеров для Leaflet. Может импортировать `L0–L3`.
- `L5` (`src/l5-ui`): компоненты React, страницы энциклопедии, интерактивная карта Leaflet и HUD. Может импортировать `L0–L4`.

## Основные команды CLI
- `npm.cmd run dev` — запуск dev-сервера Vite (`http://localhost:5173`).
- `npm.cmd run check:layers` — проверка отсутствия обратных зависимостей между слоями `L0–L5`.
- `npm.cmd run test` — запуск unit-тестов Vitest (TDD для фильтров сложности, санитизации Fandom API и реестра команд).
- `npm.cmd run sync:fandom` — синхронизация/обновление реальных выдержек статей с `https://the-long-dark.fandom.com/ru/api.php` в `src/l2-models/data/fandomSynced.json`.
- `npm.cmd run verify` — полный цикл верификации (слои + типы TypeScript + тесты + production-сборка).
