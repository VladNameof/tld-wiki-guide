# ❄️ The Long Dark — Справочник Выжившего и Интерактивная Угольная Карта (`tld-wiki-guide`)

Атмосферный русскоязычный справочник по игре **The Long Dark** (включая дополнение *Tales from the Far Territory*), вдохновлённый структурой `https://the-long-dark.fandom.com/ru/wiki/` и эстетикой внутриигровой картографии древесным углём.

## ✨ Ключевые возможности

1. **Двухуровневая атмосферная карта-атлас (Leaflet `L.CRS.Simple`, `2144×2412`):**
   - **Глобальная схема Острова Великого Медведя** со всеми **15 регионами** (включая Дальние земли *Tales from the Far Territory*) и маршрутами переходов.
   - **Детальные геодезические угольные атласы регионов** в двух темах (*«Уголь на пергаменте»* и *«Полярное сияние»*) с метровой рамкой `100..2000 м` (`A1–H8`), контурами проходимых долин, уличной застройкой со значками удобств, 100+ подлокациями, водопадами, тросами, точками старта игрока (`S`) и полной легендой (**47 условных знаков** + управление 5 слоями полотна).
2. **Живая перестройка полотна карты под уровень сложности:**
   - Переключение между режимами **Пилигрим**, **Странник**, **Сталкер**, **Незваный гость** и **Страдания** перестраивает само полотно карты: часть домов превращается в сгоревшие руины с печными трубами, альпинистские тросы меняют статус (*привязан* / *снят*), огнестрельное оружие и готовые луки исчезают, уступая место маршруту ковки и гарантированным спавнам молота, лупы и спичек (`★`).
3. **Дневник выжившего и свои заметки углём:**
   - Отмечайте обследованные постройки и бункеры (`✓`), отслеживайте процент зачистки каждого региона.
   - Кликайте по карте для нанесения собственных угольных меток (схроны с мясом, временные лагеря, маршруты хищников) с сохранением в `localStorage` и экспортом/импортом JSON.
4. **Все разделы энциклопедии + Интеграция с Fandom MediaWiki API:**
   - Полные каталоги регионов, экипировки и одежды, фауны и флоры, болезней и механик крафта/торговли.
   - Мгновенный глобальный поиск (`Ctrl+K`) одновременно по локальной базе и напрямую по живым статьям `the-long-dark.fandom.com/ru/api.php` (с защитой от XSS / Untrusted Input).

## 🚀 Быстрый старт

```bash
npm.cmd install
npm.cmd run dev
```

Дополнительные команды:
- `npm.cmd run sync:fandom` — обновить локальный кэш реальных статей с русскоязычной Fandom Wiki через MediaWiki API (`src/l2-models/data/fandomSynced.json`).
- `npm.cmd run test` — запустить модульные тесты Vitest.
- `npm.cmd run check:layers` — проверить чистоту архитектурных слоёв `L0–L5`.
- `npm.cmd run build` — собрать оптимизированную статическую версию в `dist/` (готова для GitHub Pages / Vercel / Cloudflare Pages).
